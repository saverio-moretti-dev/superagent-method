# Checklist di validità di un test (tutte vere, altrimenti scartare e ripetere)

1. **Cecità verificata**: `check_blind.py` dice CIECO (nessun file letto, solo WebSearch/WebFetch, nessuno strumento di altri tipi); il testo non cita istruzioni dell'utente o del progetto.
2. **Ricerche davvero fatte** (numero adeguato, pertinenti; apri qualche URL a campione).
3. **Ha letto tutta la consegna** (cita dettagli specifici non banali).
4. **È rimasto nel ruolo** (non parla da consulente servizievole).
5. **Verdetto coerente con le motivazioni**; obiezioni specifiche, non generiche.
6. **Pertinente e nel formato richiesto.**
7. **Nessuna allucinazione decisiva** (fatti dell'azienda non presenti nel contesto né nelle fonti).
8. **Stabilità**: se i tester divergono, leggi perché; non mediare.

Sospetti: nessuna obiezione concreta = test troppo gentile, non informativo; 0 ricerche = test non valido; ha cercato l'email/nome dell'account = non valido.
Un test valido e negativo non si scarta mai perché «scomodo».
